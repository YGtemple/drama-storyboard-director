# drama-storyboard-director

把剧本转成镜头表，按 15 秒分段。

<sub>Skill · `SKILL.md` + references</sub>

---

## 产出什么

给一段剧本，输出一张镜头表。每一行是一个镜头：

| 列 | 内容 |
|---|---|
| 镜号 | 段内顺排 |
| 时长 | 秒——对白通常 3–8 秒，反应镜头更短 |
| 景别 | 全景、中景、近景、特写 |
| 机位 | 固定、推、摇、手持 |
| 画面 | 看得见什么、发生了什么 |
| 台词 | 若有，连表演提示 |
| 声音 | 环境音与音效 |

## 为什么是 15 秒一段

短视频平台奖励开头几秒的钩子，也奖励每一个边界上「继续看下去」的理由。按 15 秒切分，就逼着在每个边界回答一个问题：凭什么让人越过这个点？

纸面上读着通顺的剧本，在这里会散架。这正是这个练习的意义。

## 参考材料

`references/` 放着这套方法依赖的工艺笔记——景别怎么承载情绪、固定机位什么时候比运动机位更好、怎么把信息压缩进一个画面。

## 目录

```
SKILL.md       方法主体
references/    工艺笔记
```

## 用法

把 `SKILL.md` 加载进支持技能包的 agent，再交给它一份剧本。产出是表格，不是成片——镜头还是要自己拍。
