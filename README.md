# drama-storyboard-director 仓库说明文档

> 一句话简介：从业20年短剧导演分镜技能 · 剧本→15秒分段快切专业分镜表

> 本说明基于对该仓库 `main` 分支全部文件的实际逐文件读取整理而成。

## 一、项目概述与定位

`drama-storyboard-director`（短剧分镜导演）是一个面向豆包 AI 助手的**短剧分镜拆解技能包（Skill）**。它模拟"一位从业 20 年的短剧导演"，把用户已有的**剧本拆解成可直接拍摄、可直接剪辑的专业分镜脚本**，服务于即梦等 AI 视频生成、短视频短剧分镜拆解场景。

- 许可证：MIT
- 仓库规模：约 7KB，纯 Markdown 文本，无二进制资源
- 核心信条：镜头服务情绪而非机械平均切镜；每镜 ≤6 秒；同一人不连续占两个镜头；情绪越激烈切镜越快；**严格保留原剧本台词不改写**。

## 二、核心功能与工作流

工作流程四步：
1. 先通读剧本，理解人物关系、情绪走向、爽点位置；
2. 按 **15 秒一段**拆分，每段秒数独立从 1 开始计数（不足 15 秒仍独立成段，不合并不凑数）；
3. 逐镜头拆解，**每镜 ≤6 秒**，**总时长 ≥70 秒**（不足时补镜头扩展）；
4. **补镜头不补台词**（可补环境/道具/手部/眼神/反应镜头，不可加剧情台词），最后直接输出六列分镜表成品，不解释。

## 三、技术栈与依赖

本仓库是纯提示词/规范类技能，无可执行代码、无第三方运行依赖。输出物为结构化分镜表文本，下游供即梦等 AI 视频生成平台使用。

## 五、核心文件逐一解读

### 1. `SKILL.md`（核心入口）
带 frontmatter（`name`+`description`）。包含：
- **角色定位**：从业 20 年短剧导演；
- **工作流程**：通读→15秒分段→逐镜拆解→补镜不补台词→输出六列表；
- **输出格式**：固定字段为 镜头序号 / 时间（如 0-3s）/ 景别 / 运镜方式 / 场景 / 人物 / 画面细节细化 / 原版台词（无台词填"—"）；
- **核心铁律**：
  - 时长：每镜 ≤6 秒、语速 3–5 词/秒（英文台词）、台词 >5 秒必须拆成两镜、总时长 ≥70 秒、时间轴连续不重叠不跳空；
  - 台词：严格保留原文、不改写不润色不增删、不翻译，长台词必须穿插反应/道具/视线/手部/环境/过肩镜头或景别变化；
  - 人物：同一人不可连续作为两个镜头主体，说话超 10 字主动拆镜；
- **导演思维**：爽点识别（背叛/反杀/占有欲/权力压制/复仇/当众羞辱/生死保护/失控告白/身份压制/情绪翻盘等）、爆点加密节点（按钮按下/枪举起/巴掌落下/人被踹飞/门被踹开/血溅脸上/眼神骤变/跪下/拔枪/宣布身份或反杀前冷笑等密集快切）、情绪激烈时（崩溃/尖叫/暴怒/绝望/杀意爆发）多用特写、超特写、反应镜头、快切、急推、甩镜、手持微晃、全景切特写对比；
- **景别策略表**：大全/全景建空间与权力差、中景交代动作站位、中近/近景压缩呼吸感、特写写爽点情绪物件、反应镜头承接长对白、主观镜头表现背叛/凝视/危险、过肩镜头表现对峙逼供压制；
- **补镜规则**：原剧本动作对白少时，可补环境建立、道具特写（门窗灯血枪按钮手机酒杯锁链）、手部/眼神/呼吸、衣料血迹玻璃水风雪质感、反应/视线/脚步/空间压迫/蓄力/余波镜头——只补镜头不补剧情不补台词；
- **画面细节写法**：禁止空泛（如"表现张力""增强情绪"），必须写清拍什么、人物怎么动看向哪、空间关系变化、镜头目的、对应爽点；给出正面示例（红色按钮特写埋背叛引信、女主泪眼特写泄露后悔恐惧、门被踹开大全景拉入场气势）；
- **节奏要求**：开场 3–5 镜立住危险/欲望/冲突/悬念，每隔几秒一个视觉刺激点，情绪"压—爆—压—再爆"，结尾留钩子；
- **严禁事项**：不改写台词、不自创台词、不改事件顺序、不文学描写、不空泛形容、不全平视正反打、不长对白压单镜、不一人连续占多镜、不只拆动作不拆反应、补镜头不变补剧情。

## 六、运行 / 使用方式

本仓库是技能包而非应用程序。克隆后放入豆包技能目录刷新即可；使用时向其提供已有剧本，技能自动通读并输出 ≥70 秒、15 秒分段、每镜 ≤6 秒的六列分镜表成品，台词严格沿用原文。

## 七、适用场景与项目特点

- **适用**：短剧/短视频创作者需要把剧本快速拆成可拍摄、可喂给 AI 视频生成的镜头表；尤其适合强节奏、爽点密集的竖屏短剧；
- **特点**：
  - 高度强调"忠于原文"——台词一字不改、不改事件顺序，补镜只补镜头不补剧情；
  - 充满短剧行业的"爽点工程"思维（爆点加密、情绪波峰波谷、权力差/羞辱/反杀等情绪模型）；
  - 输出格式固定、可直接交付，强调"直接给成品不解释"；
  - 规则具体到语速词数、拆镜阈值（台词>5秒、说话>10字）、打断主体的镜头类型，工程化程度高。
