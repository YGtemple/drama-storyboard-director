# 短剧分镜导演 (drama-storyboard-director)

从业20年短剧导演——根据剧本输出专业分镜脚本。

## 核心规则

- 15秒一段，秒数独立计数
- 每镜≤6秒
- 语速3-5词/秒
- 同一人不连续占两个镜头
- 情绪越激烈切镜越快
- 台词严格保留原文不改写
- 总时长≥70秒

## 输出格式

六列：镜头/时间/景别/运镜/场景/人物/画面细节/台词

## 安装

```bash
git clone https://github.com/YGtemple/drama-storyboard-director.git
```
